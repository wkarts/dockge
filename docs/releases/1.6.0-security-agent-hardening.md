# Dockge 1.6.0 — Security & Infrastructure Agent Hardening

Esta promoção consolida a primeira linha independente/API-first com endurecimento de segurança humana e automação de infraestrutura.

## Incluído

- TOTP/2FA com segredo protegido por AES-256-GCM e invalidação de sessões por `auth_revision`;
- API Access administrável pela interface, com credenciais de uso único, SHA-256, scopes, expiração e namespaces de stacks;
- REST API de automação sem shell remoto arbitrário;
- Generic Infrastructure Agent multi-Control-Plane, com credenciais por vínculo e journal idempotente;
- Windows Service nativo, Linux systemd e macOS LaunchDaemon;
- pipelines para binários e instaladores Linux/Windows/macOS;
- descoberta/coexistência com Docker e Dockge existentes, sem remoção ou adoção automática;
- Dockerfile autocontido e imagens oficiais direcionadas a `ghcr.io/wkarts/dockge`;
- separação definitiva das regras comerciais: licenciamento, inadimplência, aprovação de upgrade e backup pertencem ao Control Plane consumidor.

## Git Flow

- `develop`: integração/homologação;
- `main`: produção estável;
- canal GHCR de homologação: `:develop` / `:develop-<sha>`;
- release estável planejada pelo workflow SemVer em `main`.

## Observação operacional

Os eventos de GitHub Actions realizados pela integração durante esta implementação não produziram novos workflow runs observáveis. A versão `1.6.0` é o próximo SemVer planejado pelo contrato de release, mas a tag/GitHub Release/imagem estável somente devem ser consideradas publicadas quando o workflow correspondente for efetivamente executado e confirmado.
